## ✦ Overview & Concept

**The Realm of Sarthak Jalan** is an immersive, dark fantasy portfolio application blending the dramatic lore and visual majesty of *Game of Thrones / Westeros* with production-grade engineering excellence.

Rather than presenting standard resume bullet points, this portfolio structures Sarthak's professional trajectory, technical innovations, and academic milestones into the noble houses and historic orders of Westeros:
- The **golden wealth and power of Casterly Rock** holds his industry engineering experience.
- The **dragonfire forge of Targaryen** guards his deployed web applications and machine learning projects.
- The **ironborn resilience of Greyjoy** enshrines verified credentials and certifications.
- The **scholarly Citadel of Oldtown** documents his academic degree in Cloud Computing and Automation at Vellore Institute of Technology.
- The **ancient honor of Winterfell** hosts the Raven Dispatch for professional correspondence.

## ✨ Key Architectural Features

### 1. ⚔️ Dark Fantasy Cinematic Design System
- **Parchment & Gold Aesthetic**: Strict adherence to refined typography pairing:
  - `Cinzel Decorative` for royal headings and titling.
  - `Cinzel` for structured heraldic labels, badges, and navigation items.
  - `EB Garamond` for warm, readable narrative body copy.
- **Dynamic Vignette & Atmospheric Layers**: Multi-layer atmospheric effects (`realm-bg-texture`, `realm-bg-vignette`, corner ornaments, gold filigree dividers, and floating embers).
- **Zero "AI Slop"**: Custom layout math, controlled border radii, no generic purple-cyan gradients, and high contrast ratios meeting WCAG AA standards.

### 2. 🎴 Interactive House Cards Navigation
- Custom interactive 3D cards with heraldic sigil images and glowing rune fallbacks.
- **Section-Aware Hover State**: Smooth CSS transitions replace house names with their functional portfolio section (**EXPERIENCE**, **PROJECTS**, **SKILLS & ARSENAL**, etc.) upon cursor hover or touch focus.
- Responsive bento grid adapting fluidly from mobile single-column to wide desktop layouts.

### 3. 📄 Built-in Scroll of Deeds (Resume Viewer)
- Integrated in-app resume viewer with:
  - Full-screen inspection modal.
  - One-click PDF download with automated fallback handling.
  - Direct print triggers.
  - Zoom and orientation controls.

### 4. ✉️ Resilient Raven Dispatch (Contact System)
- **Iframe-Safe Navigation**: Custom protocol launchers that prevent iframe sandboxing from breaking `mailto:` links.
- **One-Click Clipboard Copying**: Instant email address copy with visual checkmark feedback and a floating toast notification.
- **Webmail Direct Link**: One-click **"Open in Gmail"** launcher pre-addressing the composition window for webmail users.
- Interactive contact form with input validation and instant state confirmation.

## 🛠️ Technical Arsenal & Stack

### Frontend Core
- **React 19** (`react`, `react-dom`): Modern functional components, concurrent features, and declarative UI hooks.
- **TypeScript 5.8**: Complete end-to-end type safety (`House`, `ProjectItem`, `ExperienceItem`, `SkillGroup`, etc.).
- **Vite 6**: Ultra-fast build pipeline and HMR dev server.
- **React Router 7** (`react-router-dom`): Client-side routing with automatic route-based title, OpenGraph, and scroll-to-top synchronization.

### Styling & Motion
- **Tailwind CSS 4** (`@tailwindcss/vite`): Utility-first styling with modern CSS variables, color-mix functions, and fluid responsive breakpoints.
- **Motion** (`motion/react`): Smooth route transitions, staggered card fade-ins, and floating particle effects.
- **GSAP 3**: Precision timeline animations for intricate heraldic elements.
- **Lucide React**: Clean, semantic vector glyphs.

### Full-Stack & Machine Learning Foundation
- **Express.js / Node.js**: Optional server-side proxying and backend orchestration.
- **Google GenAI SDK** (`@google/genai`): Gemini API integration readiness for intelligent multimodal interactions.
- **Python / Scikit-learn / TensorFlow / PyTorch**: Sarthak's foundational machine learning ecosystem showcased across project demos.

## 🚀 Quick Start & Local Setup

### Prerequisites
- **Node.js**: Version `20.x` or higher
- **npm**, **pnpm**, or **bun**

### 1. Clone the Repository
```bash
git clone https://github.com/sarthakjalan06/portfolio.git
cd portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Launch Development Server
```bash
npm run dev
```
The application will launch at `http://localhost:3000` (or the configured host port).

---

## ⚙️ Environment Configuration

Create a `.env` file in the root directory (refer to `.env.example`):

```env
# Optional Gemini API Key for AI features / server routes
GEMINI_API_KEY=your_gemini_api_key_here

# Dev Server Port (Defaults to 3000)
PORT=3000
```

## 📦 Production Build & Deployment

### Build for Production
To generate an optimized, tree-shaken static bundle inside `/dist`:
```bash
npm run build
```

### Preview the Build
To preview the production distribution locally:
```bash
npm run preview
```

### Run Type Checks & Linting
```bash
npm run lint
```

### Deploying to Cloud Hosts
- **Vercel / Netlify / Cloudflare Pages**: Set build command to `npm run build` and output directory to `dist`.
- **Google Cloud Run / Docker**: The repository includes support for containerized deployment running behind standard ingress proxies on port 3000.
